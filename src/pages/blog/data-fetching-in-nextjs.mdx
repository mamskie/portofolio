Clerk adalah layanan autentikasi modern yang memudahkan penambahan fitur sign-in, sign-up, dan manajemen pengguna secara aman di aplikasi Next.js Anda. Berikut adalah panduan langkah demi langkah mengintegrasikan Clerk di aplikasi Next.js Anda.

## Langkah 1: Daftar dan Buat Aplikasi Clerk

Kunjungi https://clerk.dev dan buat akun. Buat aplikasi baru di dashboard Clerk Anda. Catat Frontend API key yang akan digunakan nanti.

## Langkah 2: Instalasi Clerk SDK

Jalankan perintah berikut di root project Next.js Anda: npm install @clerk/clerk-react @clerk/nextjs atau yarn add @clerk/clerk-react @clerk/nextjs

## Langkah 3: Konfigurasi ClerkProvider

Bungkus aplikasi Anda dengan ClerkProvider untuk menyediakan konteks autentikasi. Edit file pages/\_app.tsx seperti berikut:

import { ClerkProvider } from '@clerk/nextjs';
import type { AppProps } from 'next/app';

export default function App({ Component, pageProps }: AppProps) {
  return (
    <ClerkProvider {...pageProps}>
      <Component {...pageProps} />
    </ClerkProvider>
  );
}

Pastikan environment variable yang diperlukan sudah diatur agar Clerk bisa berfungsi.

## Langkah 4: Proteksi Halaman dengan Autentikasi

Gunakan HOC withAuth untuk membatasi akses halaman hanya bagi pengguna yang sudah login. Contoh di halaman profil:

import { withAuth, UserButton } from '@clerk/nextjs';

function Profile() {
return (
<div>
<h1>Profil Anda</h1>
<UserButton />
</div>
);
}

export default withAuth(Profile);

Pengguna yang belum login akan otomatis diarahkan ke halaman sign-in.

## Langkah 5: Halaman Sign-In dan Sign-Up

Manfaatkan komponen bawaan Clerk untuk halaman masuk dan daftar:

// pages/sign-in.tsx
import { SignIn } from '@clerk/nextjs';

export default function SignInPage() {
  return <SignIn path='/sign-in' routing='path' />;
}

// pages/sign-up.tsx
import { SignUp } from '@clerk/nextjs';

export default function SignUpPage() {
  return <SignUp path='/sign-up' routing='path' />;
}

## Langkah 6: Mengakses Data Pengguna

Gunakan hook useUser untuk mendapatkan informasi pengguna di komponen mana pun:

import { useUser } from '@clerk/nextjs';

export default function Dashboard() {
  const { user } = useUser();

return (
<div>
<h2>Selamat datang, {user.firstName}!</h2>
<p>Email: {user.primaryEmailAddress.emailAddress}</p>
</div>
);
}

## Langkah 7: Atur Environment Variable

Tambahkan kunci frontend Clerk ke .env.local:

NEXT_PUBLIC_CLERK_FRONTEND_API=<your_frontend_api_key>

Clerk SDK akan otomatis membaca variabel ini.

## Langkah 8: Deployment

Saat deploy (misal di Vercel), pastikan environment variable sudah diatur di setting project.

---

## Tips Tambahan

Anda bisa menyesuaikan tampilan UI Clerk dengan mengoverride komponen atau styling. Kelola pengguna dan setting autentikasi dari dashboard Clerk. Clerk juga mendukung login sosial seperti Google, GitHub, dan lainnya dengan mudah.

---

Dengan integrasi Clerk, Anda dapat menambahkan autentikasi yang aman dan skalabel dengan setup minimal, sehingga bisa fokus mengembangkan fitur aplikasi Anda.
